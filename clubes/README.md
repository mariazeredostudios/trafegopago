# Clubes

Registro por clube, para acompanhar particularidades de cada conta/campanha
(orçamento, dependência de orgânico, próxima data de seletiva, link/UTM
específico). Criar um arquivo `<clube>.md` por clube conforme as campanhas
forem mapeadas com dados reais da conta.
