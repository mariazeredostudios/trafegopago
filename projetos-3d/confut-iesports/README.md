# Estande iESPORTS × Confut Sudamericana — apresentação 3D interativa

Protótipo de apresentação visual do estande institucional da iESPORTS na
Confut Sudamericana, para validação com o cliente antes do fechamento da
arte final de impressão.

Este projeto é independente do trabalho de tráfego pago descrito no
`CLAUDE.md` da raiz do repositório — foi versionado aqui a pedido do
cliente, dentro do mesmo repositório de conta.

## Arquivo

- `apresentacao.html` — apresentação autocontida (HTML/CSS/JS puros, sem
  dependências externas), com 7 slides navegáveis: capa, conceito, planta
  baixa e zoneamento, render 3D interativo do estande, ficha técnica por
  superfície, projeto luminotécnico e mapeamento executivo. Abrir
  diretamente no navegador.

## Base técnica usada

- Documento técnico do estande padrão fornecido pela organização da Confut
  Sudamericana (3,00×3,00m, 2 painéis backlit de 2,70×2,20m, balcão de
  0,90×0,40×0,90m, sangrias de 10cm/2,5cm etc.).
- Mockup de divulgação da iESPORTS/Confut (referência de composição).
- Mural `iESPORTS` (1920×1080px) com o elenco multi-clube das seletivas —
  usado no painel de fundo.
